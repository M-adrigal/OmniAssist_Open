# OmniAssist

一个轻量级 AI Agent 框架，基于技能系统（Skill）实现工具调用，支持自然语言动态创建和管理技能，无需编写代码即可扩展 Agent 的能力。

## 特性

- **双界面支持**：提供 Web 前端界面和终端命令行两种交互方式，共享同一套 Agent 核心
- **多用户系统**：支持用户注册、登录、权限管理（RBAC），每位用户可独立配置模型参数
- **自然语言创建工具**：用自然语言描述需求，Agent 自动生成完整的工具定义，包括参数、执行逻辑等
- **自然语言工具管理**：创建、更新、删除、查看工具全部通过自然语言对话完成，无需记忆命令。管理员专属权限（创建/更新/删除），全员可查看
- **智能工具生成**：利用 LLM 知识自主确定 API 细节，优先使用免费公开 API，减少手动配置
- **自动验证**：工具创建或修改后自动执行自测，确保工具可用
- **三种执行模式**：
  - `local_execution`：本地执行代码，适用于计算、数据处理、文件生成等
  - `http_request`：调用外部 API，适用于天气查询、汇率查询等
  - `llm_simulated`：由 LLM 直接返回结果，适用于信息查询、内容生成等
- **联网搜索**：支持 Tavily 搜索引擎，可智能识别用户意图（实时信息、事实知识、教程指南、对比分析等场景）并自动优化搜索策略
- **沙箱隔离**：工具代码在独立 venv 虚拟环境和子进程中执行，带超时保护，确保安全与稳定
- **多会话管理**：支持多轮对话、多会话切换、上下文管理，会话持久化存储
- **流式响应**：AI 回答实时流式输出，支持中途停止
- **思考过程可视化**：可切换显示/隐藏模型的思考过程（自然独白风格），思考内容、联网搜索记录与工具调用记录以可折叠面板展示（顺序：思考过程 → 联网搜索 → 工具调用 → 最终回答），最终回答始终可见
- **历史对话预览**：切换会话时完整还原历史消息的四段式布局，支持折叠/展开
- **登录页美化**：毛玻璃效果登录框（`backdrop-filter`），浮动动画光斑背景，4 个时段渐变背景（早晨/下午/傍晚/夜晚），支持亮色/暗色双模式
- **主题切换**：三态循环切换（自动 → 暗色 → 亮色），自动模式跟随操作系统主题偏好
- **文件管理**：前端可浏览、预览和下载工具生成的文件，点击文件名即可在新标签页中预览（支持 PDF、图片、文本等格式）
- **上下文压缩**：支持设置上下文 token 上限（如 32k、64k、128k），自动压缩历史消息避免超限
- **日志系统**：统一格式的结构化日志，支持按天/大小轮转，错误日志分离，线程安全的用户上下文注入，方便问题排查
- **用户级技能仓库**：系统技能与用户技能物理隔离，用户可创建/修改/删除自定义技能，系统技能仅管理员可维护，同名用户技能覆盖系统技能
- **意图关键词自优化**：基于用户输入动态匹配意图关键词，支持按用户存储和自动优化，提升工具选择精准度
- **任务复盘系统**：记录任务执行日志，自动分析失败模式，生成 Skill 优化建议
- **多用户独立沙箱**：每位用户拥有独立的 venv 虚拟环境，依赖完全隔离，避免多用户共享依赖池导致的版本冲突
- **子 Agent 调度**：支持多子 Agent 配置文件，按需加载，通过 AgentPool 统一管理。支持动态创建临时 Agent 处理一次性任务，任务完成后自动释放
- **条件并行执行**：多工具调用时自动并行执行（ThreadPoolExecutor），单工具调用直接执行，避免不必要的线程开销
- **Per-Session DOM 隔离**：每个会话独立的 DOM 容器，切换会话时保留完整内容，不再丢失消息
- **输入安全校验**：消息长度限制（10000 字符）、会话标题长度限制（200 字符）、不存在会话拒绝访问（404）
- **暴力测试套件**：覆盖 API 冒烟测试、并发压力测试、安全边界测试，token 消耗可控（~4万/次）

## 快速开始

### 环境要求

- Python 3.10 及以上（代码兼容 3.10~3.14，本机开发与测试使用 3.14）
- OpenAI 兼容的 API 端点（可使用任何兼容 OpenAI API 格式的服务）
- （可选）Tavily API Key，用于联网搜索功能

### 安装

```bash
pip install -r requirements.txt
```

### 启动 Web 服务

```bash
python server/main.py
```

服务默认运行在 `http://localhost:17520`。

首次使用会自动创建 SQLite 数据库并生成默认管理员账户：
- **用户名**：`admin`
- **密码**：`admin123`
- ⚠️ **首次登录必须修改密码**，修改后才能使用平台功能

登录后可在设置中配置模型参数（API Key、Base URL、Model Name）和 Tavily 搜索 API Key，配置后重启无需重新输入。

管理员可在用户管理页面创建其他用户，并分配不同角色权限。

### 数据库管理

服务启动后自动启动数据库管理界面（基于 sqlite-web）：

- **地址**：`http://localhost:17521`
- **认证**：使用管理员账号 `admin` 和当前密码登录
- 仅管理员可访问，普通用户无法通过认证

### 终端模式

```bash
cd agent
python main.py
```

进入交互界面后，使用 `/model set` 命令配置模型参数。

## 技能系统

项目采用技能（Skill）架构，每个技能是一个包含 `SKILL.md`（YAML 定义 + Markdown 指令）和 `scripts/`（Python 脚本）的文件夹。系统技能由管理员维护，用户技能存储在 `agent/skills/user/{user_id}/` 下，同名用户技能覆盖系统技能。

### 使用已有技能

直接在对话中描述需求，Agent 会自动匹配并调用相应技能：

```
用户：帮我算 123 * 456
Agent：123 × 456 = 56088

用户：今天几号
Agent：今天是 2026 年 8 月 7 日，星期四

用户：帮我写一篇文章，保存为 Word 文档
Agent：Word 文档已保存至 document_output/word_output/
```

### 创建自定义技能

用自然语言描述你需要的技能，Agent 会自动完成分析、生成、验证全流程：

```
帮我创建一个可以查询任意城市实时天气的技能
```

也可以批量创建或更新：

```
帮我更新 weather 技能，增加湿度参数
删除 weather 技能
帮我看看现在有哪些技能
```

Agent 会自动完成以下步骤：

1. **理解需求**：分析技能用途，确定所需功能和执行方式
2. **生成技能**：创建 `SKILL.md` 和 Python 脚本
3. **自测验证**：自动执行测试，确保技能可用
4. **立即可用**：保存后即可在对话中调用

> **权限说明**：创建、更新、删除技能仅限管理员操作，普通用户可查看技能列表。

## 联网搜索

项目集成了 Tavily 搜索引擎，支持智能场景识别：

| 场景 | 说明 |
| --- | --- |
| 实时信息 | 天气、股价、新闻等时效性查询，自动附加当前日期 |
| 事实知识 | 百科类知识查询，搜索结果作为补充参考 |
| 最新动态 | 版本更新、趋势动态，按时间倒序整理 |
| 教程指南 | 操作步骤类查询，整理为清晰的分步指南 |
| 对比分析 | 多事物对比，从多维度系统分析 |
| 本地化信息 | 地点相关查询，确认地点一致性 |
| 通用搜索 | 默认搜索模式 |

搜索结果会以可折叠面板的形式展示在思考过程下方（思考结束后才显示），包含搜索场景、关键词和搜索结果详情，用户可随时展开查看。搜索过程中，搜索信息会先融入思考内容。

在 Web 界面设置中配置 Tavily API Key（可在 [https://tavily.com](https://tavily.com) 免费注册获取）即可启用。

## 用户与权限

系统内置基于角色的访问控制（RBAC）：

| 角色 | 权限 |
| --- | --- |
| `admin` | 全部权限：用户管理、全局模型配置、工具管理、搜索配置等 |

管理员可在 Web 界面创建、编辑、删除用户，分配角色。

## 审批与权限模式

平台对敏感操作提供**双权限模式**与**聊天框审批门**，在保证 Agent 能力的同时防止 LLM 自动执行不可信代码。

### 两种权限模式

| 模式 | 说明 |
| --- | --- |
| `request`（请求批准，默认） | 敏感操作执行前，需在聊天框逐项确认（允许 / 拒绝 / 跳过） |
| `full`（完全访问权限） | 敏感操作直接执行，不再弹确认卡片（提权模式，前端持续提示） |

模式以**会话（session）** 为单位隔离，多用户并发互不影响；仅会话拥有者可切换，防越权。

### 风险分级（_classify_skill_risk）

登录时按技能来源与执行模式自动判定风险，决定是否需要审批：

- **系统内置技能**（管理员维护）：视为可信，在已加固沙箱中执行，**免审批**
- **用户自建技能**（local_execution）：标记为 `exec`，`require_approval=True`，**必须经过审批门**
- **用户自建技能**（http_request）：标记为 `write`，`require_approval=True`，**必须经过审批门**

> 设计原则：仅可信系统技能免确认；任何用户自定义代码默认不可信，需人工逐项确认后才执行（纵深防御）。

### 审批交互

- 敏感操作触发时，前端在输入框上方弹出**审批卡片**，列出待确认项
- 每项提供 **允许 / 拒绝 / 跳过** 三个按钮，**点击即执行**，无需先选中再提交
- 全部项决议后，Agent 循环被唤醒继续；中途停止则整组决议记为拒绝
- 所有审批与模式切换写入 `logs/audit.log` 以便追溯

### 信任模式（角色级免确认）

持有 `tools:execute_sensitive` 权限的角色（如管理员），可在信任模式下免除逐项确认，直接执行敏感操作。

## 安全机制

- **用户认证**：基于 HMAC-SHA256 签名的 Token 认证，30 分钟过期
- **密码加密**：SHA256 哈希存储，不保存明文
- **API Key 加密**：敏感信息使用 XOR + SHA256 派生密钥加密存储
- **输入校验**：消息长度限制（10000 字符）、会话标题长度限制（200 字符），防止资源耗尽攻击
- **会话验证**：发消息时校验会话是否存在，不存在的会话返回 404
- **执行隔离**：工具代码在独立 venv 虚拟环境和子进程中运行，崩溃不影响主服务。每位用户拥有独立的沙箱环境，依赖完全隔离
- **内存限制**：沙箱进程内存上限 512MB（`resource.setrlimit`），防止内存耗尽攻击
- **超时保护**：每次执行设有超时限制，防止死循环
- **模块管控**：9 层安全防护（进程隔离、venv 隔离、导入拦截、OS 函数禁用、文件删除控制、网络拦截、超时保护、环境隔离、用户隔离）
- **路径安全**：文件操作限定在指定目录内，防止路径穿越攻击
- **权限校验**：API 路由层进行角色权限校验，防止越权操作
